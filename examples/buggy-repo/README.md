# Three-bug practice repository

This repository intentionally contains three bugs. Run `node --test` to observe failures.
Fix the implementations in math.js while preserving the tests and documented behavior:

- average(values): arithmetic mean; empty input throws.
- discountedPrice(price, percent): price after the percentage discount.
- clamp(value, minimum, maximum): constrain value to the inclusive range; invalid bounds throw.

No packages or network access are required. A successful repair makes all five tests pass.
